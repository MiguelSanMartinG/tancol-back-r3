# Integración: empleados que cumplieron la meta

Lista del dashboard. Una fila por empleado y producto comercial que cubrió su meta en la última semana ya cerrada.

Requiere JWT.

```
Authorization: Bearer <token>
```

Base local: `/api/v1`. Producción: `https://back.purificadoratancol.com/api/v1`.

No lleva parámetros. El backend calcula la semana. No está dentro de `GET /dashboard/kpis/official`.

Si nadie cumplió, `cumplidas` llega vacía y `total` es `0`. El periodo sí viene.

## Semana

Hora de Ciudad de México. La semana va del lunes 00:00 inclusive al viernes 13:00 exclusive.

Si el viernes 13:00 de la semana en curso todavía no llega, la lista es la semana anterior. A partir de ese corte, es la semana que acaba de cerrar.

Ejemplo consultado el martes 13 de octubre de 2026: lunes 5 de octubre 00:00 a viernes 9 de octubre 13:00.

Lo vendido el viernes después de las 13:00, el sábado o el domingo no entra. Una venta con fecha exactamente `13:00:00` tampoco entra.

## Qué cuenta

Entra una meta semanal que haya estado vigente en esa semana, aunque después se haya cerrado. No entran metas eliminadas ni metas creadas después del corte.

`cantidadVendida` suma la cantidad de liquidaciones en estado `FINALIZADA` de ese empleado y ese producto, por la fecha de la liquidación.

Cumplió cuando `cantidadVendida` es mayor o igual a `cantidadMinima`.

El orden es por nombre de producto y, dentro del producto, por nombre del empleado.

## Request

```
GET /api/v1/dashboard/kpis/metas-empleados-cumplidas
```

Producción:

```
GET https://back.purificadoratancol.com/api/v1/dashboard/kpis/metas-empleados-cumplidas
```

| Campo | Uso en pantalla |
| --- | --- |
| `periodoInicio` | Inicio de la semana, lunes 00:00 |
| `periodoFin` | Corte, viernes 13:00. No inclusive |
| `total` | Cuántas filas hay en `cumplidas` |
| `cumplidas[].empleadoNombre` | Persona. Nombre y apellidos |
| `cumplidas[].productoNombre` | Producto |
| `cumplidas[].productoAlias` | Alias. Puede ser `null` |
| `cumplidas[].cantidadMinima` | Meta |
| `cumplidas[].cantidadVendida` | Cantidad vendida en la semana |
| `cumplidas[].cubierto` | Siempre `true` en esta lista |
| `cumplidas[].empleadoId` | Para abrir al empleado. No va como texto |
| `cumplidas[].productoId` | Para abrir el producto. No va como texto |
| `cumplidas[].metaId` | Id de la meta. No va como texto |
